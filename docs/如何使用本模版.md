# 如何使用本模版

按下面四步，从「空模版」变成你自己的人生备份仓。

## 1. 把本仓库设为 GitHub Template（可选，维护者）

1. 打开仓库 **Settings** → **General**
2. 勾选 **Template repository**
3. 保存后，别人（或你自己）可用 **Use this template** 一键建新仓

## 2. 用模版新建私人副本（推荐日常用法）

1. 在模版仓页面点 **Use this template** → **Create a new repository**
2. Owner 选你的账号；Repository name 自定（例如 `my-personal-world`）
3. 可见性选 **Private**（完整个人档案建议私人；仅展示版可选 Public）
4. 创建后克隆到本地：

```bash
git clone git@github.com:YOUR_USERNAME/YOUR_REPO.git
cd YOUR_REPO
```

若没有「Use this template」，可 Fork 后再在 Settings 里改为 Private，并清理无关历史按需重开仓。

## 3. 填写各目录

1. 阅读根目录 `README.md` 与各子目录 `README.md`
2. 复制示例并去掉 `.example` 后缀，例如：
   - `profile/about.example.md` → `profile/about.md`
   - `products/catalog.example.md` → `products/catalog.md`
   - `timeline/2026.example.md` → `timeline/2026.md`
3. 把虚构演示内容改成你的**可公开**信息
4. 在 `learning/notes/` 写笔记；在 `assets/` 放可公开图片
5. 提交并推送：

```bash
git add .
git commit -m "填充个人档案骨架"
git push
```

## 4. 永远不要把秘密提交进 Git

- 不要提交：密码、`.env`、API Key、私钥（`*.pem`）、身份证/银行卡扫描件、真实详细住址
- 已配置 `.gitignore` 忽略 `secrets/`、`private/`、`*.env`、`credentials*` 等；若仍误提交，立刻轮换密钥并从历史中清除
- 公开仓默认「任何人可读」；不确定能不能公开的，就不要放进仓库
- 更敏感的材料：用密码管理器或加密网盘，而不是 GitHub

完成以上步骤后，你就有了一份可版本控制、可迁移的「个人世界备份」骨架。
